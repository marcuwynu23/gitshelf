Features

Self-hosted

Run GitShelf on your own server or machine. Your code and metadata stay on your infrastructure—no vendor lock-in.

Docker compatible

One-command deploy with Docker and Docker Compose. Backend and frontend images included; optional SSH support.

GitHub alternative

Familiar Git workflows without relying on GitHub. Create repos, push and pull over HTTP or SSH, browse in the web UI.

Repository management

Create, list, and organize repositories. Simple naming and access control tailored for small teams and personal use.

File explorer

Browse repository contents with a folder and file tree. Open files and navigate branches from the web interface.

Commits viewer

See the latest commits per repository. Author, message, and date at a glance for quick history checks.

Get started

Clone the repo

Get the source from GitHub and install dependencies with pnpm. Backend and frontend can run locally for development.

Run with Docker

Use docker-compose up to start backend and frontend. Repos and DB are persisted in Docker volumes.
